# Repaint sources

Generated with the built-in image generation tool, using each matching `_guide.png` as its edit target. The guides are unlit orthographic renders of the original hull with the previous added plates removed. Camera matrices and orthographic dimensions are in `projection_cameras.json`.

The three repaint PNGs are projected onto the real hull. `scripts/project_repaint.py` creates visibility weights; `scripts/pack_projection_atlas.py` assigns view-packed atlas coordinates, and `scripts/smooth_repaint_seams.py` bakes continuous blends across camera transitions. The final color asset is `textures/hull_repaint_final_8k.png`; its PBR companion is `textures/hull_repaint_atlas_orm_2k.png`. The three guide/repaint PNG pairs are source artwork, not screenshots of the finished game asset. The completed hangar is preserved separately.
